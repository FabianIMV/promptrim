Write a commit message for the staged diff.

Follow Conventional Commits. The subject line must be at most 72 characters and must start with one of:
feat, fix, docs, refactor, test, chore.

Use the imperative mood: "add", not "added" or "adds".
Never mention the tool that generated the change.
Do not include a body when the diff touches fewer than 10 lines.
When you do include a body, wrap it at 72 columns and explain why, not what.

Output only the commit message, with no code fences and no preamble.
